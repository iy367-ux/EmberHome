01 / The project

Made for the
way TVs work.

Television is a different kind of screen. You sit further away. You navigate with a remote. EmberHome is an independent launcher project focused on a clean home-screen experience and practical D-pad navigation.

04 / Compatibility

Know before
you install.

Android TV firmware varies between manufacturers. Check the Android version and release notes before installing; a compatible APK does not guarantee every device feature will behave identically.

Existing editions

Published EmberHome editions have supported Android 4.4.4 and newer, depending on the specific build and device.

Check each release

Legacy · Android 4.4.4

The KitKat-compatible line is being deprecated. Historical builds are preserved for existing devices, but should not be expected to receive new features or ongoing maintenance.

Legacy support · limited future updates

Future development

Active development is moving to Android 6.0 (API 23) and newer. Check release notes for the minimum Android version of each build.

Android 6.0+ direction

Keep a way back

Do not disable or remove your device's stock launcher as a routine installation step. Keep it available in case you need to switch back.
